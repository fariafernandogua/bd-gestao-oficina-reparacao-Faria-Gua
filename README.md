# bd-gestao-oficina-reparacao-Faria-Gua
Base de dados desenvolvida em MySQL para organizar e facilitar a gestão de uma oficina de reparação de computadores. O projecto permite registar e acompanhar os clientes, os equipamentos, as reparações e as peças utilizadas, ajudando a manter as informações organizadas e a tornar o trabalho da oficina mais simples e eficiente.
